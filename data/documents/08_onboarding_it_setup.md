# IT Setup Guide for New Hires

## Accounts You'll Receive
- Corporate email (firstname.lastname@acme.example)
- Slack workspace
- GitHub organization membership
- Okta SSO for all internal tools
- VPN client (Tailscale for engineering, Cisco AnyConnect for everyone else)

## Laptop
Engineering hires receive a 16" MacBook Pro. Non-engineering roles receive a 14" MacBook Air. Windows machines available on request.

## Password Manager
1Password is required for all employees. Install it during your IT setup session; your recovery kit will be printed and mailed to your desk (or home address for remote hires).

## Getting Help
File tickets in Jira Service Desk. Urgent issues: page the IT on-call via PagerDuty.
