# Security Awareness Basics

All Acme employees complete annual security training. This document summarizes key expectations.

## Phishing
- Verify unexpected requests for credentials, wire transfers, or gift cards via a second channel.
- Report suspected phishing to security@acme.example.

## Passwords and MFA
- Use 1Password for all account credentials.
- Enable hardware-key MFA on all critical systems. SMS-based MFA is being phased out.

## Data Handling
- Customer PII is classified as Restricted and must not be copied to personal devices or unmanaged storage.
- Screenshots containing customer data should not be posted in public Slack channels.

## Incident Response
Suspected security incidents should be reported to the on-call security engineer via PagerDuty. Do not attempt to investigate on your own.
